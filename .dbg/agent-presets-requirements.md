# Agent 预设页交互需求汇总（用户原话整理）

## 已确认的设计（不改）
- 名片式卡片：头像（圆形遮罩，未来图片）+ 昵称 + 信任级徽标（系统/用户）+ 岗位 + 擅长什么（prompt 首行 2 行截断）+ 经验 + 模型行 + 岗位维度 chip + chevron
- 筛选维度 pill 行：全部/研发/产品/设计/市场/自媒体/创作 + 右侧搜索框
- 3 列网格，不足 3 张补「虚位以待」占位卡（ghost 图标 + 虚线描边 + 同宽高）
- 官方基础模式只读组（4 张玻璃小卡，「官方」徽标）
- 右上角「+ 新建预设」按钮
- 编辑为二级页面（非弹窗），左上角返回

## 当前待讨论/定稿的问题

### Q1. 二级页面布局
- 名片预览位置：用户指出「名片预览左侧全部空着」不合理。当前方案：返回行（左上）+ 名片预览（右上 248px 卡），表单从下方全宽开始。是否还有更好的布局？
- 表单各组顺序/分组是否合理？

### Q2. 「官方 Agent 模式」改为「继承自」
- 用户：「选择官方 Agent 模式，改为继承自。这个后续展示在名片上，加个标签展示。」
- 含义：corum profile 的 baseMode 字段（standard/ptc/minimal/cordis）在名片上显示为「继承自 standard」标签
- 需要讨论：标签文案/位置/样式？名片上已有「系统/用户」信任级徽标 + 岗位维度 chip，再加「继承自」标签是否会拥挤？

### Q3. 提示词放大编辑
- 用户：「提示词编辑我希望能有个放大的符号 点击可以占满整个右侧区域，方便编辑。并提供 AI 润色」
- 已设计：提示词组标题行右侧「放大」按钮 → 占满右侧内容区（大号 textarea）+ AI 润色按钮 + 「缩小」按钮
- 需要讨论：放大态的交互细节（保存后自动缩小？还是手动缩小？AI 润色在放大态的行为？）

### Q4. 所有进一步交互的完整状态图
- 用户：「将所有进一步的交互都绘制出来」
- 需要梳理：名片主页 → 二级设置页 → 提示词放大 → 技能绑定弹窗 → MCP 绑定弹窗 → 删除确认 → 新建预设 → 保存后回到主页，完整链路的所有状态和跳转关系
