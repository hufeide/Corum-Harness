# Corum Harness v0.2.0

> 基于 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 底座构建的**通用 Agent 软件**——把 agent loop、工具系统、多 Agent 编排、记忆、技能打包成开箱即用的产品，面向**编程场景**与**通用 Agent 场景**。

本仓库为 **open core** 模式的开源形态：**任务模式（Task Mode）**——单任务泳道 + 指挥模式 + 完整 Agent 能力面（编排、子 Agent、记忆、MCP、技能、编程工作台）。

## ⚠️ 安装前必读（macOS）

- **平台**：本包仅供 **macOS Apple Silicon（arm64）**。Windows / Linux 尚在规划中。
- **未签名 / 未公证**：本 release 未做 Apple 公证。**首次打开会被 Gatekeeper 拦截**——请**右键点击 `Corum.app` → 打开**（或在「系统设置 → 隐私与安全性」里点「仍要打开」），之后即可正常使用。
- **推荐下载 `Corum-0.2.0-arm64.dmg`**（挂载后拖入「应用程序」）；`Corum-0.2.0-arm64-mac.zip` 为等价压缩包（解压即得 Corum.app）。

## 核心能力

- **多 Agent 编排**：`orchestrate` 声明式 fan-out，子 Agent 在独立 git worktree 中工作并自动集成；子 Agent 卡片可见可控（查看提示词 / 改动 / 跳转会话）
- **指挥模式（Conductor Mode）**：技术负责人带队伍的基础模式——指挥者只读门禁 + 三阶段调研 + 委派闸门，人类指挥 + AI 执行的协作范式成为可选 Agent 形态
- **Agent 预设**：岗位 / 人格 / 职责 / 域边界 / 模型路由（主 / 子 / 调查三档独立配置）
- **记忆底座**：事实级存储、存续期与衰减
- **MCP 集成 + 技能库 + 本地模型（Ollama）+ 文生图**
- **编程工作台**：Monaco 编辑器 + 文件树 + 终端 + 对话区，可拖拽重组

## 版本与基座

- **应用版本**：`0.2.0`
- **底座版本**：DeepSeek Harness `0.1.5-rc.3`（基座号只在「复制诊断信息」中可见；应用版与基座版分两条线维护）
- **环境要求**（自行构建）：Node `^22.19.0 || >=24.0.0`，pnpm `11.7.0`

## 从源码构建

```sh
pnpm install
pnpm shell:dev        # 开发态启动桌面应用
cd packages/desktop && pnpm run pack   # 打包 macOS 应用（.app / .dmg）
```
